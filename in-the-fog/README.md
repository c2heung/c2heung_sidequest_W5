# In the Fog

## Project Description
"In the Fog" is a simple web project that creates an immersive experience with layers of fog that scroll horizontally across the screen. The project utilizes HTML, CSS, and JavaScript to achieve a soft, airy aesthetic with a gradient background and animated fog layers.

## Project Structure
```
in-the-fog
├── src
│   ├── index.html        # Main HTML document
│   ├── styles
│   │   └── main.css      # CSS styles for the project
│   └── scripts
│       └── fog.js        # JavaScript for animating fog layers
└── README.md             # Project documentation
```

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, etc.)

### Running the Project
1. Clone the repository to your local machine.
2. Navigate to the `src` directory.
3. Open `index.html` in your web browser.

### Features
- Soft airy gray gradient background.
- Three fog layers with varying opacities and blurs.
- Endless horizontal scrolling animation for a calming visual effect.
