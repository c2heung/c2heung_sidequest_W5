## Description

"In the Fog" is a simple webpage that creates an immersive experience with layers of fog that englessly scrolls horizontally across the screen. In the distance, you can see a house, some trees, and a few cars driving by, all shrouded by the fog.

---

## Learning Goals

Learning Goals:

- Create a world larger than the screen
- Use parallax and animated/layered motion
- Control the camera/world movement
- Evoke emotion through space pacing and timing
